ORCHESTRA


Initial condition


Porosity, water volume, saturation degree and temperature are adapted according to  


Option _null_


Only applicable for uniform initial conditions that are defined in the ORCHESTRA input file


Option _table_


Initial concentrations are defined in a table; for each com. The concentrations are then recalculated to amount in each cell


orch_ini

-headings mat ca+2.diss ca+2.min

-rowid mat

-start

1 1E-3 0

-end


       rowid mat : indicates that the initial conditions are defined for the different materials.


The first row indicates that:  

for material 1, initially there is a solution concentration of 1E-3 mol/l and no Ca in solid phases


For each node, ca+2.tot is then calculated by ca+2.diss * VolumeofWater + ca+2.tot
