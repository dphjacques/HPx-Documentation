Add database group and database

In this example, we illustrate how a database group and a database is added to the HPGeochemistry or HPx embedded in HYDRUS 5.x  codes.  We add the database ThermoChimie ...


Copy database to default folder

In a first step, the database is added to a separate folder in the default folder for the databases.


Open the Settings & Preferences dialogue window via in the main menu toolbar, select the Settings tab and select the Database tab.

Select and copy the text of the default folder for the database. By default installation of HYDRUS 5.x, this is


       C:\Users\Public\Documents\PC-Progress\HYDRUS 5.x\HPx\Databases\


Via e.g. Windows Explorer, create the folder ThermoChimie

Copy the text file of the ThermoChimie database in that folder.


Adding new database group and database


Open the Database Manager via in the main menu.

Create a new database group by the Create a New Database Group button .

In the New Database Group Metadata dialogue window:

  • Select Default Folder
  • Type the name of the database group in the Name textbox. Use the name of the folder you created earlier (ThermoChimie)
  • Click OK

Add the database to the database group by the Open Existing Database button .

Select the database file.

Add information in the Database Metadata dialogue window according to your requirements.

Click OK.
