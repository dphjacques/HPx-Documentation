HYDRUS: 1D cation exchange example

This example simulates the chemical composition of the effluent from a column containing a cation exchanger and is adapted from Example 11 of the PHREEQC manual.


Acronym 1DCEC01


Problem definition

An 8-cm long column initially contains a Na-K-NO3 solution in equilibrium with the cation exchanger. The column is flushed with a CaCl2 solution. Ca, K and Na are at all times in equilibrium with the exchanger. The simulation is run for one day.

The soil has a porosity of 0.5 and a saturated hydraulic conductivity of 12 cm/d (0.0001389 cm/s).  The bulk density is 1.5 kg/dm³. Dispersivity is 0.2 cm.

The initial Na-K-NO3 solution is made by using 1 x 10-3 M NaNO3 and 2 x 10-4 KNO3 M. The inflowing CaCl2 solution has a concentration of 6 x 10-4 M. Both solutions were prepared under oxidizing conditions (in equilibrium with the partial pressure of oxygen in the atmosphere). The amount of exchange sites (X) is 0.55 meq / dm³ soil. With a bulk density of 1.5 kg/dm³; this corresponds to a soil with only 0.0367 meq/100g soil (0.55 dividing by bulk density and by 100).

The column is discretized into 40 finite elements (i.e., 41 nodes). The example assumes that the same solution is initially associated with each node. Also, we use the same exchanger composition for all nodes.

A constant flux of 1 cm is applied on a column with a fixed pressure head of 0 cm at the bottom initially in gravitational equilibrium with the fixed pressure head at the bottom.


TUTORIAL


It is assumed that a managed project is created via hpgeochemistry (see Define a new managed project) including the transport folder (21_transport-models, see xx). The transport project is created via the HYDRUS 5.x GUI.


Define main settings and water 

Open the project manager of HYDRUS 5.x (), select your project in the Project Groups tab.

Go to the Projects tab and create a new project

In the text box Name, write the name of the name of the transport project (1DCEC01)

In the text box Description, add a description, e.g. "Transport and Cation Exchange, single pulse "


Open the Domain type dialogue window and select "1D - Simple" as the Domain Type.

Define general and  water flow parameters

In the Main Processes dialogue window, check Water Flow, Solute Transport, and HP-1.

In the Geometry dialogue window, set the Depth of the Soil Profile to 8 cm.

In the Time Information dialogue window, set Time Units to seconds, Final Time to 86400, Initial Time Step to 180, Minimum Time Step to 180 and Maximum Time Step to 350.

In the Output Information dialogue window, set Count to 12.

In the Soil Hydraulic Parameters dialogue window, select Soil Catalog Loam and change the saturated water content (Qs) and saturated hydraulic conductivity (Ks) to respectively, 0.5 and 0.0002777.

In the Water Flow Boundary Conditions dialogue window, set the Upper and Lower Boundary Condition to Constant Pressure Head.

Define solute transport and the geochemical model

In the HP1 Input Data dialogue window:

Reactive Transport Panel

       Select the database phreeqc.dat

       Under the Selection of Components item, select Ca, Cl, K, N(5) and Na.

Solution Definitions Panel

       Define the initial and boundary solutions (SOLUTION) as shown below.

Geochemistry Panel

       Define the exchanger (Exhange) as shown below


EXCHANGE 1001

-material 1 

X 0.55E-3

-equilibrate with solution 1


Output Panel

       Define specific output via selected_output, user_punch and selected_graph as shown below.


Selected_output

-totals Na K Ca Cl N(5)

-molalities CaX2 KX NaX 

USER_PUNCH

-headings mNaX mKX mCaX2 eNaX eKX eCaX2 eqNaX eqKX eqCaX2

-plot_units "M" "M" "M" "meq/100g" "meq/100g" "meq/100g" "-" "-" "-"

-plot_titles "Concentration" "Concentration" "Concentration" "Equivalent" "Equivalent" "Equivalent" "Equivalent Fraction" "Equivalent Fraction" "Equivalent Fraction"

-mybasic

-start     

    #convert to mol/kg soil

    bd = 1.5 #kg/dm3

    punch( mol("NaX") * tot("water") / bd)

    punch( mol("KX") * tot("water") / bd)

    punch( mol("CaX2") * tot("water") / bd)

    

    #convert to meq/100 g soil

    punch( mol("NaX") * tot("water") / bd *100) 

    punch( mol("KX") * tot("water") / bd *100) 

    punch( 2*mol("CaX2") * tot("water") / bd *100) 

    

    #Equivalent fraction

    punch( mol("NaX") / tot("X") )

    punch( mol("KX") / tot("X") )

    punch( 2*mol("CaX2") / tot("X") )

-end
