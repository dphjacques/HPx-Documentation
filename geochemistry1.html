geochemistry

-geochemistry [<string:option>] <string:solver> [<string:name>]


Identifier to set the geochemical solver during the transport calculations.


By default, PHREEQC is used as the geochemical solver. 



option

string: eiter icon or bcon. If present, it indicates the solver for calculating the initial condition (icon) or  boundary conditions (bcon). If not present, it indicates the solver used for the transport calculations.

If solvers for icon or bcon are not defined, PHREEQC is used to obtain the initial and boundary conditions.


For now, only the PHREEQC solver is present for calculating the initial and boundary conditions via the standard input in HPx:

icon

By default, the total amount (moles) for each of the components for each node is stored in a dictionary with as keys the element names ("O" for Total_O, "H" for Total_H, and e.g. "Ca", "Na",...) and as items lists with the nodal values (zero-based index). 

This dictionary can be used in the function solvers using the function GetInitialConditions().

bcon
